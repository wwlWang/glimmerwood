# 渲染联调记录

日期：2026-10-15。此记录覆盖技术样例，不代表正式主角、动画质量或完整首版已验收。

## 结果与证据

环境沿用 `evidence/development-tools-2026-10-14` 的本机记录；实际加载列表与设置保存在 `evidence/rendering-2026-10-15/state.json`。使用 MC 1.21.1、NeoForge 21.1.248、Java 21、RTX 4070 Laptop，1920×1080、12 区块视距、关闭垂直同步，帧率设置值 260。

- GemRender 蒙皮角色、Mellow 动态阴影与 Photon 透明微粒同时显示。组合截图：`evidence/rendering-2026-10-15/reload-5.png`。
- 五次完整资源重载成功，每次只存在一个预览实例；循环粒子自动重建。状态与每次截图见同一证据目录。
- 窗口依次切换为 1280×720 和 1920×1080，实际帧缓冲尺寸匹配；最终性能测量使用恢复后的 1080p。
- 60 秒独立性能采样取得 7595 个帧间隔：平均 126.62 FPS，帧时间中位数 7.44 ms，P95 10.86 ms，P99 16.32 ms；最大 120.85 ms，16 帧超过 50 ms。它只是单角色静态场景基线，不能证明跑酷、复杂场景或长时间运行的性能。
- `animation-stream.mp4` 是 20 秒、1920×1080、30 FPS 输出，共 600 帧；实际采集 562 帧，38 个时隙保持前一帧。清单在 `run-devtools/devtools/animation-stream-2026-10-15/frames.json`。已抽帧检查角色、阴影与微粒；正式动作衔接尚未验收。
- 初版 `animation.mp4` 因 PNG 写入瓶颈只采到 60 帧，不能用于流畅度判断，保留作为失败记录。
- 从未修改的下载原件重新生成 v008 源文件及导出物，GLB 和贴图哈希与 v007 一致；见 `asset-reproducibility.json`。

## 已定位的问题

1. 无贴图 glTF 材质落到 Flywheel 默认方块图集，导致杂色。导出增加独立 PNG 与图片的 `extras.resourceLocation`，开关光影均复测正常。
2. Mellow 默认关闭动态阴影。兼容预设显式打开动态阴影、2048 阴影图和 0.5 实体阴影距离比例。
3. Colorwheel 下默认圆形阴影成为过黑圆盘。光影开启时不添加该组件，改用实际蒙皮几何投影；关闭光影时技术预览保留原版阴影。
4. 光影重建后 Photon 缓存旧渲染目标。开发接口调用 `IrisCompat.invalidate()` 后，开关光影均能保留可见微粒，截图为 `run-devtools/devtools/shader-off-binding-refresh.png` 和 `shader-on-binding-refresh.png`。正式设置入口仍待集成。
5. 资源重载清除循环效果。样例持有运行实例并检查有效性，失效后在同一锚点恢复，离开世界或锚点改变时停止。
