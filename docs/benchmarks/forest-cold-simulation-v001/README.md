# 全2025起点冷态离线模拟（实现前证据）

原实施投入线是预测≤1800ms、总和不超过+5%。A+B+C的最大值1826.085ms，因此最初按未通过报告，没有自行开始实现。审核随后明确批准实施：预测最大值加本批留一校准最大绝对残差73.531ms约1899.616ms，仍值得投入验证。**正式验收仍每点每轮≤2000ms**，模型误差不抵扣。此残差只是本批经验记录，不是统计置信上界或任何新起点的误差保证。

A提前门口五列，维护独立的core中位数组与core+门口既有幅度约束；B按同RandomState/生成器/高度范围/4×4单元去重；C只在实际owner森林通过core、门口和原outer四角后做单层R2，邻区不递归。yield拒绝不写base缓存，临时框只参与XZ判定。A+B按重新执行的单元并集计费，不把两份节省相加。A/B/C均未在此录制期间接入生产。

C让18个原本base拒绝的实际森林尝试提前执行R2（不是此前102−30=72个候选都必然增加工作）。C相对A+B最大新增成本105.836ms，位于(104,54)，没有产生新的1800ms超线点。原先29点未涵盖的(61,31)、(56,26)在现状模型分别2049.269/2025.342ms，组合后1331.113/1250.786ms，保留在扩展冷态名单中。

(108,43)是组合最慢点：自身森林144个单元，R2邻区(110,38)先查溪谷19个，再核对优先的森林146个；B去重13个，最终296个单元，加41次builder原版列查询。两座森林都接受，C不能跳过outer。其现状三次实测1927.356/1930.486/1925.426ms；模型现状1898.396ms，低估约27–32ms。因此不把1826ms当作正式结果。(60,24)517→282个单元，预测2881.729→1578.818ms。

## 数据与校准

输入：现有6075基础判定；补录扩大到2209个潜在起点（原2025加外围184），共6627基础判定。777条补录包含缺失邻区以及外来资格冷工厂；森林提前门口/四角缺列另外记录；115个接受base的实际builder记录原版列查询数。补录只在evidence隔离classes中运行，958个生产文件SHA零变化。启动首轮因辅助类放错模块失败，未进入世界，原始日志保留；修正模块后编译/录制/正常保存均exit0。

“现状”模拟与29×3=87条实测逐一核对：evaluate调用顺序、单元数及单元身份派生高度项、原版噪声查询数全部相同。再以87条墙钟值拟合三个计算项和固定包装项：

T(ms)=5.475821×单元数 + 0.047480×Σ((80−该单元记录高度中位数)/8) + 3.990159×原版height/column查询数 +16.418788。

该拟合将exact单元的地形差异作轻量修正，缓存命中不重复付单元成本。每个起点开始前所有模拟缓存清空，起点内部共享base、selection、资格和B单元缓存；没有借用上一行的热缓存。冷态总和是独立冷起点之和的近似，**不是全区共享缓存的实际系统CPU**，也不是正式A/B。包装项是慢点校准外推，廉价拒绝点会被保守高估；去掉统一包装项后的总计算项为201.895→175.899秒（−12.875%），不改变慢点和通过判定。新的single-flight查询/不可变对象管理开销尚未实测。

校准残差：MAE14.883、RMSE19.847、绝对P90 36.783、绝对max58.775ms。按起点留一（一次排除该点全部3轮，避免同点泄漏）：MAE18.547、RMSE25.277、绝对P90 48.847、绝对max73.531ms。完整87行见calibration.tsv；不可把这些经验最大值当成严格误差界。村庄资格冷查询在补录中记录，29点校准本身没有村庄工厂，按同一原版列成本外推，这一覆盖局限保留。

原始证据：evidence/forest-r116-stage4-approach-fix-20261028-v001/forest-external-implementation-v001/cold-simulation-v001/，含run-02/simulation-inputs.json、workload-verification.json、四个simulation-*.json、隔离启动参数、exit和生产SHA。simulate.py仅用于离线预测；可用 `python3 docs/benchmarks/forest-cold-simulation-v001/simulate.py evidence/forest-r116-stage4-approach-fix-20261028-v001/forest-external-implementation-v001/cold-simulation-v001` 在保留原始录制时重算。没有作为生产依赖。
