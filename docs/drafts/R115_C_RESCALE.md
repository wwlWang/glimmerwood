## 稳态 FPS 复核方法

首轮河岸树景2.376427 FPS 原样保留；反向4.956018，同机位空模型3.953389、恢复模型3.748288，空模型配对差5.19%。夜间树景2.7391/反向4.9795也保留。沼泽首轮日6.0170/6.3374、夜5.9528/6.3607。前后固定45秒等待无法证明网格已经编译完，以上不当作最终稳态结论。

`ChunkCompileProbe`只在devtools，通过Sodium公共F3接口读排队Permits、Busy线程、U上传结果和P0/P1/P2待构建队列；任一非零或格式不可读都不就绪。`isTerrainRenderComplete()`只看提交队列，单独用它会漏掉忙线程和待上传。`perf_sample.chunkCompile`保留原始调试行。`capture-ginso-steady-perf.py`要求全零持续5秒，每个状态连续测三次15秒，每秒记录队列并验证全零；同一140格机位/视距16/FOV80/1920×1015/Fancy云/无光影/llvmpipe，同一存档的树景、反向、隐藏模型、恢复模型。空模型仅改变绘制，世界方块、遮挡和光照不改；退出前恢复。
