## 外形与路线

`GinsoEscapeLayout.forTree(seed, entrance, shape)` 读取实际树皮、扭转中心与最高断叉，生成三格宽半阶螺旋，再经弯钩根枝抵达开放树杈。94台起步，出口脚位H−4（104–114）；每步升幅≤0.5，三格净空，无额外能力要求。出口只有地面、根沿和真实栅栏，头顶可见天空。附层完全不写WINDOW/玻璃、LIGHT占位灯或封闭顶盖；光点用嵌在根枝里的Ginso SAP。

实际v3树的连续空心主干止于H−29附近（79–89层），高于94的空间已分裂成三叉。因此有树皮处沿真实内侧，断裂空隙由弯曲根枝相接，没有为满足“内壁”虚构一个高到冠顶的新圆筒。根枝转弯跟随种子/入口朝向，末段对齐实际高叉，不能只按树高套11个固定矩形。264样本中185个没有直接切穿原生树皮的中心线，经过原有三叉间断口（cleftIndex=0）；这是待审造型取舍，不能声称全部种子都有封闭内壁段。较高树采用更长行程，使玩家与固定水速的升高节奏匹配。

曲线先按实际树形测量，选择旋向、绕行角和弯钩长度，再栅格化为半阶；转角以完整人体斜向扫掠验证，避免内角半阶擦身。三格宽踏面边缘使用课程同种暗橡木栅栏（真实1.5格碰撞）或原有实体树皮。普通步行可达范围逐格检查；故意二段跳越过护栏属于离开逃亡包络，关2判负，不将栅栏顶作为正常步行路线。
