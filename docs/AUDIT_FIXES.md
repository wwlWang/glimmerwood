## R4：伤害打断

只有造成有限正值伤害的外部生物攻击或外来投射物命中会打断动作；发射器等无主投射物也计入。自身来源排除。火焰、中毒、仙人掌、饥饿、窒息/溺水、跌落及其他无攻击者的环境伤害正常扣血，不中断刀、弓、冲刺、Bash、牵引、下砸或滑翔。死亡、入水、菜单和其他既有不可用条件仍按原规则处理。

服务端伤害事件统一取消战斗与移动，客户端响应权威结果。Bash 因受击退出时保留当前速度，随后应用原版击退；手动或超时退出恢复暂停前速度，避免近期环境掉血造成动量丢失。旧实现的 14 项误打断已复现并保留报告；修复后 Windows / Linux 均通过 85 项 JUnit 与 109 项 GameTest。实机 14 组检查全部通过，包含客户端弓停止使用和 Bash 释放；证据为 `audit-r4-damage-v002-2026-10-18`。

后续缺动画压力测试复现一次弓取消时序问题：原版停止使用标记先于战斗状态到达时，按住右键会重新蓄力。客户端现收到 idle 结果即锁定当前按住的右键，直到松开；不再依赖使用标记的到达顺序。`audit-r6-animation-v002-2026-10-18-actions` 的 17 组检查通过，其中弓受击在三种不同输入时点重复验证，持续按键没有重新蓄力；v001 失败记录保留。
