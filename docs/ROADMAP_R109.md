# R109–R111 路线（灵战祭坛 · 幽暗深处 · 驿站扩建）

2026-10-21 起草（Claude 规划与验收，Codex 实现）。R106–R108 已完成并通过客户端验收（`dd297dd`、`0512eab`、`fbb3c90` + `02dcb0b`）。

**这批要解决的问题：** R108 给了模组一个结局，但通关前后在野外能做的事仍以遗迹为主。原作里还有三类让世界耐玩的内容没有覆盖：
1. **专门的战斗挑战。** WotW 的战斗祭坛（Combat Shrine）：封闭的竞技场、几波敌人、通关奖励碎片。这里已有喷吐者、鸦、甲虫三种敌人，可以直接组合成波次。
2. **以光为核心的环境危险。** WotW 的霉木深渊（Mouldwood Depths）：黑暗本身会吞噬 Ori，只有靠光前进；BF 的遗忘废墟也要带着光源走。模组已有灵灯、灵闪、光爆、光敏灵台，可以串成一处“没有光就会死”的地下区域。
3. **把灵光与收集品花回家园。** WotW 泉水林间里 Grom 用矿石盖房、Tuley 用种子让林间开花。R107 的驿站只能买卖；这里让玩家投入收集品，驿站随之扩建。

- **R109 灵战祭坛**：稀有地表结构，三波战斗，通关得未拥有的碎片。
- **R110 幽暗深处**：地下结构，黑暗会持续伤害玩家，只有灵光来源能保护；终点有生命格、能量格和碎片。
- **R111 驿站扩建**：新收集品「林石」与第三位居民「建筑师」，用林石和灵光完成驿站项目，项目带来实际功能。

通用约定与 [ROADMAP_R106](ROADMAP_R106.md) 相同：Codex 实现并跑全量测试，不做 git 写操作；Claude 审查、提交并实机验收；客户端与 Gradle 互斥；客户端一律用 `LIBGL_ALWAYS_SOFTWARE=1 GALLIUM_DRIVER=llvmpipe DISPLAY=:0` 启动；每轮先交 5–10 行实现计划；纹理原创且程序生成；中英文同步；提示和台词遵守 R97/R102 的文案标准；结构改动只影响新生成的区域；**谜题和封闭区域要用全模板寻路测试证明不能绕过、失败或失足后能撤离**（R104 的教训）；远离测试模板的 GameTest 场地必须自己持有区块票（R108 的教训）；画面效果要给同机位前后对比和量化数字（R108 的教训）。

## R109 灵战祭坛（Combat Shrine）

**原作：** WotW 各地的战斗祭坛：进入后入口封闭，连续几波敌人，全部击败后获得碎片。**MC 适配：** 野外稀有的原创圆形祭坛结构，精灵形态右键中央祭台开始试炼。

### 结构 `spirit_shrine`

- 生成 NBT + `TemplateStructurePiece`，约 25×14×25：下沉的圆形石质竞技场（半径约 10），一圈灵木立柱，中央祭台，单一入口阶梯。地面平整，场内无可躲避的高台死角；有 2–3 个低矮掩体，敌人和玩家都能绕行。
- 陆地群系，排除海洋、河流、沙漠、恶地、冰刺、蘑菇岛；spacing/separation 先按 32/12 区块起步，用 `verify-outpost-density.py` 同类探针给出 seed 样本的最近距离中位数与最大值，目标中位数 ≤ 1500 格。与遗迹、驿站、灵树、腐化地带互斥。
- 地形适配复用 R107 的台地/阶梯做法（起伏上限、向下补地基、入口阶梯）。
- 生成时登记进 R107 的 Feature 索引（新类型 SHRINE）。

### 试炼

- 精灵形态右键祭台：入口与场边升起**祭坛屏障**（新方块 `shrine_ward`，半透明发光、试炼中完全碰撞、试炼外不存在），封住半径约 11 的竞技场，高度覆盖到结构顶。参与者 = 开始时场内存活、非旁观玩家，最多 8 人，快照固定。
- 三波，每波开始前在生成点有 20 tick 紫色漩涡预警，敌人只在场内合法地面出现：
  1. 3 只喷吐者；
  2. 2 只甲虫 + 2 只喷吐者；
  3. 2 只鸦 + 1 只甲虫 + 2 只喷吐者。
  多人时每多 1 人，每波额外 +1 只喷吐者（上限 +3）。
- 当前波全部击败后间隔 60 tick 进入下一波。试炼中场内不自然刷怪，潮夜不在场内生成。
- **失败**：全部参与者死亡、离开竞技场超过 3 格（屏障外的意外情况，如末影珍珠）、换维度或断线，或总时长超过 6000 tick。失败时清除试炼敌人、撤除屏障、祭台恢复可用，可立即重试，不扣任何东西。
- **成功**：屏障撤除，祭台转为已完成外观（常亮），每位参与者各得一次：一枚未拥有的碎片（从未拥有的碎片中随机；全拥有则改为 150 灵光）+ 50 灵光。个人回执按祭坛坐标记录，同一人重复挑战只给 20 灵光，其他玩家仍可拿首次奖励。
- 试炼状态写入 SavedData；区块卸载或服务器重启时视为失败并清理（不保留半场状态），日志记录原因。

### 「萤」与指引

- 提示 `shrine`：首次接近祭坛 16 格内。台词：首次开始试炼、首次通关。遵守原开关与优先级。
- 制图师路路新增“最近未完成的灵战祭坛”指引（55 灵光）；地图石/地图碎片也纳入。

### 调试

- `/ori shrine start|stop|status|nearest`（OP）；devtools `spirit_state.server.shrine`：`state`、`wave`、`remaining`、`participants`、`elapsed`、`ward`（屏障是否在位）。

### 测试

- JUnit：波次组成与人数加成；失败/成功判定；奖励选择（未拥有碎片、全拥有改灵光、重复挑战只给少量灵光）。
- GameTest：
  1. 开始后屏障在位，全模板寻路证明玩家与敌人都不能离开竞技场；成功或失败后屏障全部撤除、从场内能走回入口；
  2. 三波按序出现，敌人只在场内；
  3. 参与者全部死亡、离场、超时各自判失败并清理，可重试；
  4. 奖励每人一次，碎片不重复拥有；
  5. 卸载/重载后不残留屏障和试炼敌人。
- 验收脚本 `scripts/verify-r109.py`：自然祭坛定位、真实按键打完三波（可用 `/ori` 给满技能）、屏障外观、波次预警、奖励与面板、失败重试。

## R110 幽暗深处（Gloom Hollow）

**原作：** WotW 霉木深渊：黑暗会逐渐吞噬 Ori，必须靠 Flash、发光植物和灯前进；BF 遗忘废墟里带着光源过关。**MC 适配：** 一处原创地下结构，内部的“深暗”区域只认**灵光来源**，火把等原版光源无效，所以不能靠放火把绕过。

### 机制：深暗

- 只在 `gloom_hollow` 结构的 piece 范围内生效，结构外的洞穴不受影响。
- 玩家处于深暗且没有灵光保护时，**暗蚀值**每 tick +1，满 60 后每 20 tick 受 2 点伤害（护甲照常减免）；回到受保护的位置时以每 tick −3 退回。暗蚀值在 HUD 上以屏幕边缘逐渐收拢的黑紫暗角表示，并伴随低沉音效提示。
- **灵光保护**（任一即可）：
  - 已点亮的灵灯（R96）6 格内；
  - 正在使用的灵闪（R98）——玩家本人和 8 格内其他玩家；
  - 光爆（R39）落点 5 格内，持续 100 tick；
  - 新方块 **光蕈** `lumen_pod`：被任意攻击能力或灵焰命中后亮起 300 tick，半径 5；之后熄灭，40 tick 后可再次点亮；
  - 已实体化的光敏灵台（R104）上方。
- 原版方块光（火把、荧石等）**不计入**保护，界面提示里写明。和平难度下暗蚀照常显示但不造成伤害。
- 暗蚀不会把玩家定身或瞬间击杀；死亡后在结构入口外复活点（或灵魂链接）照常处理。

### 结构 `gloom_hollow`

- 地下 Y −10 到 30 之间，入口是一口从地表下沉的竖井（带灵风口或攀爬墙面可上下）。
- 3 个房间串成一条路线：
  1. **灯廊**：灵灯链，需猛击/光爆依次点亮，熟悉“走在光里”；
  2. **光蕈洞**：分散的光蕈，必须边点亮边前进，配合 1–2 只喷吐者；
  3. **暗桥**：光敏灵台组成的桥，只有在灵闪或光爆照射下实体化，脚下是深坑（坑底安全，有撤离通道回到房间起点）。
- 终点密室：1 个生命格、1 个能量格、1 枚未拥有碎片（全拥有则 120 灵光）及 3–5 个灵光容器（R103）；奖励按 piece 每人一次。
- 需要的能力：至少猛击或光爆中的一个，灵闪推荐但不强制（光蕈路线可替代）。在房间入口用萤的提示说明。
- 登记进 Feature 索引（新类型 HOLLOW）；路路指引（65 灵光）、地图石纳入。

### 测试

- JUnit：暗蚀增减、伤害节奏、保护判定（每种来源与边界距离）、原版光源不计入。
- GameTest：
  1. 结构外不触发暗蚀；结构内无保护按节奏受伤，进入灵灯/光蕈范围后回退；
  2. 每种灵光保护单独生效，火把不生效；
  3. 全模板寻路：不经过点亮机关无法到达终点；任意位置失足后能撤离到房间起点；
  4. 终点奖励每人一次。
- 验收脚本 `scripts/verify-r110.py`：真实输入走完三个房间；暗角与音效观感、光蕈点亮效果用同机位截图给出明暗对比。

## R111 驿站扩建（Glades Projects）

**原作：** WotW 泉水林间：Grom 收集戈莱克矿石建房、修屋顶、搭桥；Tuley 用种子让林间长出花草。**MC 适配：** 新收集品「林石」，驿站新增第三位居民「建筑师」，玩家用林石和灵光完成项目，项目给出实际功能。

### 林石 `glade_stone`

- 物品，不可合成，玩家拾取后自动入账到 `SpiritProgress`（新字段，旧存档为 0），面板显示数量。
- 来源（每处每人一次，按坐标回执）：遗迹秘室（R103）各 1；灵战祭坛首次通关 1；幽暗深处终点 2；净化腐化地带 1；野外稀有的「林石露头」（新方块，世界生成在地表岩石处，挖掘或能力击碎掉 1 个，生成率按每 ~600 格一处起步并用探针统计）。

### 建筑师与项目

- 驿站新增一位原创居民「建筑师」，外观沿用 R107 的商人体系；**只出现在本轮之后新生成的驿站**；旧驿站在玩家首次靠近时，若模板内预留位为空气且地面完整，才补生成建筑师，否则不生成（并在 `/ori outpost status` 里说明原因）。
- 项目按驿站各自记录（SavedData，按驿站 piece 坐标），完成后在模板预留位用结构模板放置，不覆盖非空气方块（被玩家改建过就提示无法施工）：

| 项目 | 花费 | 效果 |
| --- | --- | --- |
| 花园 | 2 林石 + 100 灵光 | 驿站周围 24 格内草地长出原创灵花；苔语每日多一种碎片可选 |
| 瞭望台 | 3 林石 + 150 灵光 | 站上去可在指引 HUD 一次显示 1024 格内全部已登记 Feature（遗迹/灵树/地带/祭坛/深处）方向，30 秒 |
| 灯环 | 3 林石 + 150 灵光 | 驿站潮夜庇护半径 32 → 48，夜晚驿站外圈灵灯常亮 |
| 训练场 | 4 林石 + 200 灵光 | 场内木桩可练习连击并显示每秒伤害；遗迹挑战最佳成绩的排行牌 |

- 每个项目每座驿站只建一次；多人共享同一驿站进度，谁出资谁的林石和灵光被扣。建造有 100 tick 的施工演出（原创粒子与音效），期间不可取消。

### 「萤」

- 提示：首次拿到林石；首次见到建筑师。台词：第一个项目完成。

### 测试

- JUnit：林石来源回执；项目花费与重复建造；预留位检查（非空气拒绝）。
- GameTest：
  1. 各来源只给一次；
  2. 花费足够时项目完成并放置结构，余额正确扣除；不足或预留位被改建时拒绝且不扣费；
  3. 灯环生效后 48 格内不刷潮汐怪，48 格外照常；
  4. 旧驿站补生成建筑师只在预留位为空时发生。
- 验收脚本 `scripts/verify-r111.py`：自然驿站、真实交互完成两个项目，前后同机位截图。
