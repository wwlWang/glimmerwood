# R106–R108 路线（腐化地带与净化 · 林栖驿站 · 意志之光）

2026-10-21 起草（Claude 规划与验收，Codex 实现）。R103–R105 已完成并通过客户端验收（`892f43b`、`a06ece7`、`8d954c2`）。

**这批要解决的问题：** 到 R105 为止，玩家能力、遗迹解谜和战斗都已经成形，但还缺原作里把一切串起来的三样东西：
1. **世界会因为你而改变。** BF 的核心体验是归还元素、让尼伯尔森林恢复生机。这里的对应做法是：野外有腐化地带，玩家净化之后，那片土地会肉眼可见地复原。
2. **有人可以交流、交易。** WotW 的泉水林间（Wellspring Glades）有一群居民和商人，玩家攒下的灵光有地方花。
3. **一个终点。** 两作都以收集“光”并恢复灵树收尾。这里集齐三道“意志之光”后，在灵树前完成一次复苏仪式，作为这个模组的结局。

- **R106 腐化地带与净化**：野外的腐化区域，带腐光水、荆棘和枯木；摧毁中心的腐化之核后，整片区域在 30 秒内逐步复原。
- **R107 林栖驿站**：原创村落结构，两位商人（碎片商、制图师），用灵光交易。
- **R108 意志之光与复苏**：两位首领和净化腐化地带各给一道光，集齐后在灵树前举行仪式，世界产生持久变化。

通用约定与 [ROADMAP_R103](ROADMAP_R103.md) 相同：Codex 实现并跑全量测试，不做 git 写操作；Claude 审查、提交并实机验收；客户端与 Gradle 互斥；客户端一律用 `LIBGL_ALWAYS_SOFTWARE=1 GALLIUM_DRIVER=llvmpipe DISPLAY=:0` 启动；每轮先交 5–10 行实现计划；纹理原创且程序生成；中英文同步；提示和台词遵守 R97/R102 的文案标准；结构改动只影响新生成的区域；**谜题和机关要用全模板寻路测试证明不能绕过、失足后能撤离**（R104 的教训）。

## R106 腐化地带与净化（Blighted Grounds & Purification）

**原作：** BF 里被腐化的尼伯尔森林，以及归还元素后的复原；WotW 里被腐烂（Decay）侵蚀的地区。**MC 适配：** 野外稀有的腐化地带 Feature，中心有一颗腐化之核。玩家摧毁它之后，地带按波纹逐步复原。

### 方块

| ID | 说明 | 行为 |
| --- | --- | --- |
| `blighted_soil` | 发黑泛紫的土，带暗紫斑点 | 可挖，掉落泥土；表面不长草；净化后变草方块 |
| `gloom_thorns` | 暗紫色荆棘丛，无碰撞（类似浆果丛） | 接触时 2 伤害（间隔 15 tick），并减速；精灵形态也会受伤；只能用剪刀或主动的灵刀、箭、蓄力灵焰、光爆、灵锤、灵矛、下砸冲击清除；自动灵焰不选取也不溅射清除，灵闪/猛击/徒手不清除；净化后变成草或花 |
| `withered_spirit_log` | 灰黑色、无光的枯死灵木，可旋转 | 净化后变 `spirit_log`（R100），亮度从 0 变为 4 |
| `gloom_core` | 地带中心的腐化之核：缓慢搏动的暗紫晶体，亮度 6，带下沉的紫色粒子 | 生存模式下手和工具都挖不动；只能用能力摧毁（见下） |

已有的 `gloom_water`（R59）复用：净化后变清水。

### 生成

- 用 Feature，不用 Structure，写入范围 ±14：近似圆形的地带，半径 10–13，边缘不规则（噪声），中心放 `gloom_core`。
- 内容：
  - 地表替换为 `blighted_soil`；
  - 1–3 片 `gloom_water` 小水洼；
  - 8–20 丛 `gloom_thorns`；
  - 2–4 棵 `withered_spirit_log` 枯树（矮小，3–6 格高，无叶）。
- 生物群系：沿用 `#orimod:has_spirit_tree`，再加沼泽和红树林沼泽。稀有度约 1/160 区块。生成步骤用 `local_modifications`（与 R100 灵树相同，要在原版树之前）。
- 和灵树、遗迹互斥：12 格内有树心或遗迹时放弃生成。

### 腐化之核

- 生命值 40，记在方块状态 `DAMAGE`（0–4 档，外观的裂纹逐档加深）或方块实体里，实现方式由 Codex 选。
- 受伤来源：蓄力灵焰（12）、灵锤（10）、光爆（8）、灵矛（6）、灵闪持续照射（每秒 4，7 格内）。刀、箭和徒手打都**不能**伤到它，碰到时出火花、发出“叮”声，同时「萤」提示。
- 每次受伤会在 12 格内召唤 0–1 只喷吐者（冷却 100 tick，同时最多 3 只），形成防守战。
- **被摧毁时：** 触发净化，不掉方块或其他物品；创造模式保留核心物品供测试。

### 净化

- 从核心向外按水平距离安排复原时刻，约 **600 个有效 tick（30 秒）**覆盖全地带；预算不足或区块未加载时顺延。2026-10-21 修正：原“0.4 格/tick”与 30 秒不一致，采用 600 有效 tick。复原规则：
  - `blighted_soil` → 草方块；
  - `gloom_thorns` → 随机的草、花，或空气；
  - `withered_spirit_log` → `spirit_log`；
  - `gloom_water` → 水。
- 净化前沿出现冷白微粒；全部完成后播放一次 `SpiritFxKind.PURIFY`（新增：上升的光点加一圈扩散的光环）和声音。
- **奖励：** 触发时快照 32 格内的存活、非旁观玩家，最多 16 人，各得 60 灵光；离线者登录补发，世界中已无该玩家数据则跳过。发出后立即删除待发条目；完成记录只保留中心坐标（存在即已完成），防止重复刷奖励。
- **持久性：** 净化进度要存档（地带中心坐标 → 进度），区块卸载后再加载要能继续推进，不能留下半截腐化。
- 净化完成的地带，不会再刷潮汐怪（R101 防御加一条：已净化的地带中心 32 格内）。这是原作“复原之地即安全”的感觉。R106 实机复验修正：24→32，与树心一致，覆盖玩家16–28格刷怪环带。

### 「萤」

- 提示 `gloom_core`“萤：那颗核心在吸走生机……用灵焰或灵锤击碎它！”，半径 16。
- 台词 `first_purify`（只说一次）“萤：你听，森林在呼吸了。”

### 调试与测试

- `/place feature orimod:blighted_grounds ~ ~ ~`；新命令 `/ori blight nearest [radius]`，做法与 R100 的 `/ori tree nearest` 相同；devtools 加一个净化进度字段。
- JUnit：核心伤害矩阵；净化波推进与复原映射；奖励去重。
- GameTest：
  1. 放置后，地带内各方块齐全、核心存在；
  2. 五种有效来源伤害核心，刀、箭打无效；
  3. 摧毁核心后 30 秒内全部复原，玩家得到 60 灵光，重复摧毁或重新放置核心不再给奖励；
  4. 净化中途卸载区块再加载，能继续并完成；
  5. 荆棘伤害与剪刀采集、主动来源白名单；自动灵焰只选灵光容器，不清荆棘、不伤核心；同伴开启的精灵实际站入荆棘30 tick内掉血；
  6. 已净化地带 32 格内潮夜不刷怪，中心玩家多波为0。

## R107 林栖驿站（Glades Outpost & Merchants）

**原作：** WotW 的泉水林间（Wellspring Glades）：Opher 卖武器和技能升级，Twillen 卖灵魂碎片，Lupo 卖地图。**MC 适配：** 原创的「林栖族」小驿站结构，两位商人用灵光交易。名字、外形和台词都是原创的。

### 结构

- 新 Structure `glades_outpost`：灵木（R100 的 `spirit_log`）搭成的树屋平台、吊桥和灵灯，地面有篝火、摊位和一座 Spirit Well（复用 R41 神龛的方块与逻辑，作为传送点）。
- `random_spread`，spacing 24、separation 10 区块（384格候选网格）；独立 `has_glades_outpost` 标签覆盖林地、针叶林、丛林、热带草原、平原/雪原等陆地，排除沙漠、全部恶地、冰刺之地与蘑菇岛，不改灵树标签。只在干燥地面生成，31×31采样起伏≤10，以最高/最低地面中点作台地（采样处削/填≤5格），9格入口阶梯适配±7格。玩家第一次进入时，「萤」说台词 `first_outpost`。
- **密度验收修正：** 固定seed、至少25点，中位数≤1100格、最大≤2000格；间距不小于20/8，面板保底覆盖任意世界的极端空白区。seed107，出生点为中心的5×5/1024格网格实测684.83/1856.28格；不宣称所有种子都保证这个最大距离。
- 地图石（R62）和地图碎片（R68）的指引加入驿站；`/locate structure orimod:glades_outpost` 可以直接使用。

### 商人（实体 `glades_merchant`，两种职业）

- 外形：原创的方块拼装小型生物，大约 0.6×1.2，圆耳、长尾，毛色按职业区分。不会受伤（`invulnerable`），站桩，玩家靠近时转头。不能被拴、不能被骑乘、不会被推走。
- 交互：右键打开**交易界面**（自定义 Screen，不用原版村民界面），货币是灵光，购买后立即生效。
  - **苔语（碎片商）：** 出售玩家还没拥有的碎片，每玩家/每商人每天首次查看随机展示最多 3 种，当日保存快照；购买后不补抽，价格 80–200 灵光（按碎片强度）；每天（按游戏日）刷新一次。
  - **路路（制图师）：** 出售“指引”：最近的未完成遗迹 40 灵光；最近的未领取灵树 60 灵光；最近的未净化腐化地带 50 灵光。复用R62指引HUD。遗迹继续异步RuinLocator；灵树/腐化地带在Feature成功生成时写区块持久attachment，线程安全队列由服务端统一合并到每维度SavedData索引，查询2048格内且排除已领取/净化。已加载目标方块缺失时删除并继续，未加载直接信任索引，绝不同步加载。索引启用前已生成的旧Feature不回填；原`/ori tree nearest`、`/ori blight nearest`保持已加载扫描语义。
- **2026-10-21经济调整及实机修正：** 苔语为低价购买渠道（80–200），对齐WotW商人获取；面板保留查看/装备/卸下、最近驿站方向，并提供商人价×1.5的保底购买（120–300）。不强制出生点结构起点：海洋出生、禁用结构和旧世界都不能保证1000格内有可用地形，保底避免碎片进度被世界生成卡住。已有存档所有权、命令/创造获取不变。
- 驿站Spirit Well提供32格潮夜庇护，复用区段调色板缓存，放置/破坏立即失效；地面入口到双商人和泉水必须有可步行路径。
- 交易按钮使用“购买 · N 灵光”/“Buy · N”，按当前字体测宽；碎片行复用面板效果描述并可悬停看全文；路路独立说明找不到目标不收费。
- 价格和库存规则抽成纯函数，JUnit 覆盖。交易走服务端校验的网络包（校验灵光余额、商品是否仍有效），客户端只负责显示。

### 「萤」

- 提示 `merchant`“萤：林栖族在做买卖，带够灵光再来！”。

### 测试

- JUnit：库存刷新与去重（已拥有的不再出售）；价格表；指引查询的优先级。
- GameTest：
  1. 结构生成后，两位商人与 Spirit Well 都在，商人不受伤、不被推走；
  2. 灵光足够时购买碎片，余额扣除、碎片到手；余额不足时被拒；
  3. 伪造包（不存在的商品、负价、跨刷新周期的旧商品）被拒；
  4. 制图师写入指引目标，HUD 状态正确；
  5. 游戏日切换后库存刷新。

## R108 意志之光与复苏（Wisps of Will & Restoration）

**原作：** WotW 里从各地找回 Seir 的五道光（Wisps）；BF 结尾归还三元素、恢复灵树。**MC 适配：** 三道「意志之光」，集齐后在任意灵树前举行**复苏仪式**，作为这个模组的结局，同时给世界带来持久变化。

### 收集

| 光 | 来源 |
| --- | --- |
| 心之光 | 击败腐光之心（R50）后，祭坛上方出现，可拾取 |
| 翼之光 | 击败腐光翼母（R70）后同上 |
| 地之光 | 累计净化 3 片腐化地带（R106）后，第三次净化完成时在核心处出现 |

- 收集情况记在 `SpiritProgress.wisps`（心1/翼2/地4，旧存档默认为0）。每道光每人一份，待领按玩家/种类存入全存档账本，重复首领保留原祭坛位置；实体不自动消失，区块卸载不丢，加载后修复缺失实体且不强制加载。地之光计数复用个人不同 `purify/` 回执，逐个参与者计数，离线补奖亦生效。
- 成长面板（R99）新增一栏，显示三道光（已得点亮，未得显示剪影和获取提示）。

### 复苏仪式

- 集齐三道光后，精灵形态右键任意已领过的灵树树心，开始仪式：
  - 约 15 秒的演出：三道光从玩家身上飞向树心，树冠逐层亮起，萤绕树飞行，最后一道冲天光柱；
  - 演出期间玩家无敌、不能移动（可以转动视角），可以按 Esc 跳过。
- **持久效果（服务端，按世界，写入 SavedData）：**
  - 腐光潮夜（R101）减弱：本次原波数量向上取半 `ceil(n/2)`、只刷喷吐者；`maxNearby` 配置保持不变；
  - 已生成的灵树永久进入 `BLOOMED` 外观；树心原本光15，灵叶新增BLOOMED、光9→12及更亮贴图。只更新已加载区块，后加载补应用，全维度共享每tick最多256写入/约2ms软时间片；仪式期间先逐层更新本棵树，取消时回退；
  - 玩家获得称号成就和 500 灵光；
  - 「萤」的结局台词 `restoration`。
- 仪式每个玩家只能做一次。世界效果在第一位玩家完成时生效；之后其他玩家完成时，只拿个人奖励。断线/死亡/换维度/树心消失取消并保留三光，不留下持久定身或无敌标记。OP调试 `/ori wisp give <heart|wing|earth|all> [player]`、`/ori wisp clear [player]`、`/ori restoration status|reset`；reset清世界状态及个人回执（离线通过版本号在登录清理），反向渐进恢复灵叶，保留已得灵光/三光/R100赐福及树心原有赐福外观。

### 测试

- JUnit：收集状态位与旧存档兼容；仪式前置条件；世界效果开关。
- GameTest：
  1. 击败两位首领各得一道光，不重复；
  2. 第三次净化时出现地之光，第一、二次不出现；
  3. 未集齐时右键树心不能开始仪式；集齐后可以，结束后世界效果生效、个人奖励只发一次；
  4. 世界效果生效后潮夜的上限和组成按规则变化；
  5. 演出期间无敌、不能移动，跳过后状态一致。
