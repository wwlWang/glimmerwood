# Spirit Glow

Shader pack bundled with oriMod. It is an adapted version of **Mellow** by TheCMK:
<https://codeberg.org/TheCMK/mellow-shader> (also on Modrinth: <https://modrinth.com/shader/mellow>).
All credit for the rendering pipeline goes to the original author; please support the original pack.

Spirit Glow is not an official Mellow release and is not endorsed by TheCMK.

- License: see `LICENSE` (MIT, original notice kept unchanged below our notice) and `LICENSE-APACHE`.
- Upstream base and what was imported: `UPSTREAM.md`. Our changes: `CHANGES.md`.
- Requires Iris (tested with Iris 1.8.12 on Minecraft 1.21.1).
