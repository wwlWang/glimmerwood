# Upstream

Spirit Glow is an adapted version of Mellow by TheCMK.

- Source: https://codeberg.org/TheCMK/mellow-shader (Modrinth: https://modrinth.com/shader/mellow)
- Base commit: `3ad9445` (2026-09-19, "Bunch of fixes"); its `shaders.properties`, `block.properties`,
  `item.properties` and English language file are byte-identical to the Mellow v3.4.1a release, the
  build previously verified with Iris 1.8.12 on Minecraft 1.21.1.
- Imported: `shaders/`, `LICENSE`, `LICENSE-APACHE`. Not imported: repository screenshots/images, the
  `mellow.png` colour LUT, release/optimisation scripts.
- Changes after import are separate commits in this repository; see `CHANGES.md`.
